# 邀请页统一视觉主题设计

## 目标

统一整个公开邀请端的色相、明暗层级、照片画幅和装饰动效，使封面、正文卡片、照片章节、表单及状态页面属于同一婚礼视觉语言，同时保持移动端流畅度与可访问性。

## 修改范围

- 覆盖封面、婚礼信息、恋爱故事、地图、照片章节、席位、RSVP、页尾、加载与错误状态、背景音乐以及 Vant 控件。
- 不修改管理后台、服务端业务或数据库。
- 同步更新邀请端 README 中已过时的轮播组件、照片字段和视觉说明。

## 婚礼主题色系

- 奶油米白：页面背景、暖白内衬和浅色表面。
- 玫瑰棕：品牌主色、标题、边框和主要交互。
- 深可可：照片章节、深色文字和暗场材质。
- 香槟金：图标、细线、大字强调和装饰微光，不用于小号正文。
- 公开邀请端所有硬编码色和 Vant 默认冷灰均映射到统一主题令牌。
- 错误与拒绝状态使用低饱和陶土玫瑰色，不使用突兀鲜红。
- 正文、按钮和表单达到 WCAG AA；必要时加深主色和按钮渐变。

## 明暗层级

- 正文区域保持奶油米白与暖白卡片。
- 照片章节使用深可可玫瑰棕，作为同一色系的暗场层级，而非独立黑色主题。
- 照片章节前后增加奶油色与深可可色渐变过渡带。
- 封面与照片暗场使用固定主题遮罩，不根据照片动态提取颜色。

## 照片画框

- 封面和照片章节的主要照片区域统一为 `4:5` 竖向画框。
- 原图使用 `contain` 完整展示，不裁切人物；横图和超长竖图的余量由同色模糊背景填充。
- 照片章节仍保持每张照片一个全屏章节。
- 照片章节采用上部画框、下部文案卡轻微叠压画框边缘的结构，避免文字遮挡人物主体。
- 长描述继续在文案卡内部滚动。
- 封面文字保留在照片下半部分，通过同色渐变确保可读性。
- 短屏和横屏按可用高度等比缩小画框，不裁图、不横向溢出、不挤掉文案。
- 画框使用暖白内衬、香槟金细边和柔和玫瑰棕阴影。

## 装饰动效

- 装饰语言为香槟微光粒子、玫瑰棕线描花枝和一次性画框边缘扫光。
- 不使用花瓣雨、爱心雨、大面积闪烁、自动晃动或视差滚动。
- 封面和照片章节使用少量缓慢漂浮微光。
- 时间、故事和地点标题使用一次性花枝展开；页尾使用静态花枝落款。
- 表单、错误提示和按钮附近不放循环装饰。
- 内容入场时长统一为 500–700ms；微光循环为 10–16 秒；画框扫光仅在章节进入时执行一次。
- 动画使用独立 DOM 层、CSS 伪元素和 CSS 动画，不新增动画库或 Canvas。
- 每个装饰区域最多六个微光元素，只动画 `transform` 和 `opacity`；离开区域后停止。

## 可访问性

- `prefers-reduced-motion: reduce`：关闭微光、花枝绘制和扫光，只保留约 180ms 淡入，并取消平滑滚动。
- `prefers-reduced-transparency: reduce`：玻璃材质改为近实色背景，移除承载文字区域的模糊。
- `prefers-contrast: more`：提高文字、边框和控件对比度。
- 装饰层不参与焦点顺序，不拦截点击，不向辅助技术暴露无意义内容。

## 非目标

- 不改变邀请内容顺序、照片数据、照片章节导航和全屏预览行为。
- 不增加主题切换器、动态取色、第三方动画依赖或新的后台配置。
