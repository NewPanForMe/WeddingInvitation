# 照片故事编辑式章节设计

> 本方案包含照片自动分组与章节导语，已被“邀请页编辑式长页设计”的纯样式参考边界取代，不作为后续实施依据。

## 意图

参考婚礼纪长页请柬的章节感与杂志式图文节奏，提升当前邀请页照片故事的叙事层次；保留现有暖色主题、4:5 主画框、手动滚动、键盘导航和全屏预览，不复制商业礼物、社交浮层或强制自动滚动。

## 已选方案

选择“轻量编辑式章节”：在现有深可可色单照片章节之间插入奶油色章节导语和小型照片拼贴，形成“留白导语 → 拼贴预览 → 单图主叙事”的节奏。

考虑过但不采用：

- 完整复刻参考页：需要绝对定位画布、自动滚动和大量固定装饰，维护成本高且可访问性较差。
- 只增加章节编号：风险最低，但无法形成参考页明显的留白与图文交替效果。

## 内容分组

- 不修改接口、数据库和后台配置，继续使用现有 `photos`、`title`、`description`。
- 按照片原有 `sortOrder` 顺序自动分组，每组最多 3 张。
- 章节数由照片数量自然决定，最多展示三种罗马编号样式；超过三组后继续顺序编号，不改变照片顺序。
- 每组导语使用该组第一张照片的标题和描述；缺失时分别使用“美好瞬间”和简短固定寄语。
- 每张照片仍保留现有独立全屏 4:5 主章节，不从主叙事中删除。

## 章节导语与拼贴

- 导语区使用奶油米白背景、大面积留白、`01 Chapter I` 式编号和深玫瑰棕正文。
- 1 张照片时显示单张窄幅预览；2 张时左右错落；3 张时使用一大两小或三联图。
- 拼贴只作为章节预览，允许 `object-fit: cover` 轻度裁切；点击任意缩略图仍打开原图全屏预览。
- 导语区高度由内容决定，目标为约 `68–82svh`，不强制占满一屏；横屏改为左文右图。
- 导语与深色照片章节之间使用当前奶油色—深可可色过渡，不引入新的冷色。

## 动效

- 导语首次进入视口时，编号、正文和拼贴以 500–650ms 的淡入与轻微上移依次出现。
- 拼贴图片仅做一次性入场，不自动轮播、不漂移、不视差。
- 保留现有画框扫光和微光粒子；导语区不增加循环粒子，避免装饰密度过高。
- `prefers-reduced-motion: reduce` 下仅保留 180ms 淡入，并取消位移和错峰延迟。

## 交互与可访问性

- 现有上下方向键章节导航仍只在单照片章节之间移动，章节导语不会打乱照片索引。
- 拼贴缩略图使用真实按钮和明确的“查看第 N 张照片”名称，支持键盘打开预览。
- 标题层级保持连续，章节导语使用 `h2`，照片标题使用 `h3` 或与页面层级等价的结构。
- 长照片描述继续在现有文案卡中独立滚动。
- 无照片时不渲染照片故事；1–2 张照片时布局自动降级，不保留空拼贴位。

## 实现边界

- 新增纯函数负责稳定分组和全局照片索引，并以 Node 测试覆盖 0、1、2、3、4、7 张照片。
- 新增独立章节导语组件，`PhotoChapters.vue` 继续负责观察器、键盘导航和全屏预览。
- 更新邀请页 README 和原视觉规范中“每张照片连续暗场”的说明。
- 不修改管理后台、服务端、数据库、照片字段或邀请数据顺序。

## 验收标准

- 手机、矮屏、横屏和桌面均无横向溢出。
- 每张照片在主章节中恰好出现一次，拼贴仅为可点击预览。
- 拼贴点击、主图点击、键盘导航、坏图状态和长描述滚动均保持可用。
- 章节导语与现有主题色、减少动态、减少透明和高对比模式一致。
