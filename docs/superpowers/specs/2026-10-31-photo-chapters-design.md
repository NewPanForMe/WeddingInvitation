# 邀请页照片章节设计

## 目标

将邀请页“美好瞬间”从照片轮播改为纵向连续的全屏照片章节。每个章节展示一张完整照片、可选标题和可选描述，并在章节进入视口时呈现克制的过渡动效。

## 已确认行为

- 仅替换“美好瞬间”，封面、婚礼信息、恋爱故事、地图、席位、RSVP 与页尾保持原顺序和行为。
- 每张公开照片对应一个属于邀请页的照片章节，不创建独立 URL。
- 使用原生纵向滚动/触摸滑动；桌面端补充键盘上下方向键导航。
- 不自动播放、不首尾循环；最后一张之后自然进入“您的席位”。
- 背景使用当前照片的模糊铺满效果，前景图片完整居中，不强制裁切。
- 章节进入时照片淡入并轻微缩放复位，标题和描述错峰上浮；减少动态效果时只保留短暂淡入。
- 多张照片显示当前进度与首次滑动提示；单张照片隐藏这两项；无照片时不渲染该区域。
- 点击照片打开可缩放的全屏预览，关闭后保留原滚动位置。
- 图片加载失败时保留章节和文字，以柔和占位背景替代图片。
- 新增可空照片描述，保存前 trim，最多 500 字，保留自然换行，不解析 HTML、Markdown 或富文本。
- 新上传照片标题默认为空。公开页隐藏明显由相机、手机或时间戳生成的历史文件名标题，但后台保留原值；人工标题正常展示。
- 后台现有照片编辑弹窗增加描述输入，启停操作必须保留描述。
- 继续沿用封面加入“美好瞬间”的开关；开启后封面按普通照片章节展示。

## 兼容与可访问性

- `description` 数据库列可空，通过幂等 SQL 兼容已部署数据库。
- 公开和后台 API 的照片 DTO 均增加可空 `description`。
- 公开标题类型修正为可空。
- 章节提供可读的图片替代文本、明确的预览按钮标签和可见键盘焦点。
- 支持 `prefers-reduced-motion`、`prefers-reduced-transparency` 与 `prefers-contrast`。

## 非目标

- 不修改照片分类、排序规则或封面展示开关语义。
- 不新增富文本编辑器、独立照片详情路由或新的动画依赖。
- 不提交或推送 Git；由用户另行明确要求。
