# 邀请页统一视觉主题实施计划

> 依据：`docs/superpowers/specs/2026-10-31-invitation-visual-theme-design.md`

## 目标

将 `frontend-invitation` 统一为奶油米白、玫瑰棕、深可可和香槟金色系；封面和照片章节使用稳定的 4:5 画框；增加克制、可降级的装饰动效，同时保留现有邀请数据、照片预览、键盘导航和 RSVP 行为。

## 实施步骤

1. 扩充全局主题与间距变量，完整覆盖 Vant 的文字、背景、边框、禁用和提示色。
2. 先为装饰粒子数量边界增加失败测试，再实现最多 6 个粒子的可复用装饰组件。
3. 将封面重构为 4:5 象牙白画框、同图柔焦背景与下半部文字遮罩，并接入粒子装饰。
4. 将照片章节重构为上方 4:5 画框、下方轻叠文字卡片；保留每图一屏、长文独立滚动、图片预览和键盘导航。
5. 统一内容卡片、状态色、音乐按钮、错误页、首页和底部花饰；补齐减弱动态、减弱透明与高对比度模式。
6. 更新邀请页 README 中过时的轮播和照片字段说明。
7. 执行单元测试、类型检查、生产构建、服务端/后台回归、差异检查和浏览器多视口视觉验证。

## 验收要点

- 封面和照片画框的内容区域宽高比为 4:5，横屏及矮屏不裁切、不横向溢出。
- 装饰粒子每个区域最多 6 个，仅动画 `transform` 和 `opacity`，离屏暂停。
- `prefers-reduced-motion` 下移除循环、描线和闪光，仅保留短淡入；高对比和减弱透明模式可读。
- 金色只用于装饰或大字号重点，小字号正文满足 WCAG AA 对比度目标。
- 不修改后台、接口和数据库行为，不提交或推送 Git。
